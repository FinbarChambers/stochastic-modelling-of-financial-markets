# 0007 – Reihenfolge: Aktien/GBM als verdaulicher Einstieg

**Status:** akzeptiert (2026-11-25) · **Wer:** Finbar

## Kontext
Es gab mehrere mögliche Startpunkte (Prognosemärkte, Zinsen, agentenbasierte Modelle).

## Entscheidung
Finbar: „wir behandeln erst etwas Verdaubares, damit es auch für einen Leser verständlicher ist.“ Projekt 1 ist
GBM auf Aktien. Jedes spätere Modell wird als *Antwort auf eine konkret gemessene Schwäche* des vorherigen eingeführt
(z. B. Vol-Clustering → Heston, fette Ränder → Merton-Sprünge).

## Konsequenzen
+ Roter Faden für Leser: jede Erweiterung ist durch Daten motiviert, nicht durch Mode.
